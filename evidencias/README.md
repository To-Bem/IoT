# Evidências

Material que comprova os testes de [`docs/testes.md`](../docs/testes.md). Os nomes dos arquivos começam pelo ID do caso de teste.

| Pasta / arquivo | Conteúdo |
|---|---|
| `logs/<ID>_<descricao>.txt` | Texto do Monitor Serial do teste (ex.: `F5_queda.txt`, `H4_brownout_usb2.txt`) |
| `logs/eventos_recebidos_AAAAMMDD.csv` | Gerado sozinho pelo servidor de teste: cada evento que chegou pela rede, com horário e IP de origem |
| `fotos/<ID>_<descricao>.jpg` | Fotos da montagem, do multímetro, do painel do servidor de teste, da lâmpada acesa e em alerta |
